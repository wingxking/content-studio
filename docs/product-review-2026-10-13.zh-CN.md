# Content Studio 产品能力审查与本轮交付

核验日期：2026-10-13。当前产品运行于本机 Docker，地址 http://127.0.0.1:14310/ 。代码完成、账号可用、真实草稿和公开发布分别记录。

## 已实现的产品功能

| 功能 | 当前能力 |
| --- | --- |
| 内容任务 | 原创/热点任务，一次、每天、每周调度；独立运行记录、失败恢复和暂停开关 |
| 研究与创作 | 来源证据、研究问题、模型选择、主稿生成、平台适配；共享选题排除策略 |
| 文章工作台 | 富文本编辑、引用、图片、修订历史、针对性修改建议；保留人工修改并显示适配冲突 |
| 平台版本 | 14 个目标平台；各自标题、正文、标签、素材与格式，Product Hunt 产品资料包 |
| 独立视频 | 独立项目、脚本、CPU 配音、字幕、渲染及预览；内容批准与渲染批准独立，失败有检查点 |
| 素材管理 | LocalFS 原件、Supabase 业务状态、可恢复上传、哈希与引用检查、历史路径读取 |
| 发布治理 | 修订与账号快照、账号串行写入、审批、暂停、回执、效果记录；不确定结果先核对 |
| 已有自动渠道 | YouTube 官方 OAuth/Data API 视频流程；X/LinkedIn/Reddit 的 Postiz 文字适配代码，具体连接与权限另验 |
| 本轮草稿能力 | 微信公众号、知乎、B 站专栏通过 WechatSync 协议保存草稿；X/LinkedIn/Reddit 保存 Postiz 服务商草稿 |
| 最少操作入口 | 中文界面私密配对、实际身份识别/导入/绑定、独立保存草稿按钮、草稿核验；Docker CLI 同样可用 |
| 运行与迁移 | Docker Compose、角色 worker、Supabase 队列、加密备份恢复；新草稿网关不获得数据库/模型凭据 |

以上“已实现”不等于所有账号都已完成真实平台验收。模型给出的安全评估也不是独立内容审核或平台许可。

## 本轮验收

- 完整测试 **251 通过，0 失败，0 跳过**；严格 TypeScript 和生产构建通过。Vite 保留已有 Tiptap 指令/大包提示。
- Docker 中新建独立 Supabase 工作区，真实 HTTP 路由 → 原子队列 RPC → delivery worker → WebSocket 模拟扩展 → 持久化回执完整通过：3 个任务、3 个草稿回执、0 公开作品；重复点击没有增加写入，暂停状态保持。
- 网关测试覆盖来源/密钥校验、第二客户端拒绝、方法/目标白名单、断连、超时、轮换和凭据脱敏。生命周期测试覆盖内容/图片修订、实际账号身份、历史账号锁、未知结果与迟到回执。
- 更新前通过 Docker wrapper 完成加密逻辑备份，核验 1009 个文件；不含原始 PGDATA，密钥与备份分离。更新后 14 个服务运行，配置的健康检查通过。
- 浏览器检查看到中文配对/身份绑定、14 平台能力卡和正确禁用状态，控制台无警告或错误。指定 Chrome 配置尚无 WechatSync 扩展；未安装新扩展、未发送真实平台草稿/公开内容。
- 隔离 smoke 脚本为 `tests/draft-docker-smoke.ts`；它始终新建工作区，不能使用正式工作区。模拟回执不属于真实账号验收。
